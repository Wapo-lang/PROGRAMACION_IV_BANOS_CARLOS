## 🎯 Objetivo Principal

El objetivo fundamental de la materia **Programación IV** es capacitar en el diseño, desarrollo y despliegue de **aplicaciones móviles modernas**, abarcando tanto el enfoque **nativo** como el **multiplataforma**. 

A lo largo del curso, se integran herramientas del lado del cliente (Frontend Móvil) y del lado del servidor (Backend), permitiendo construir soluciones completas, eficientes, escalables y orientadas a resolver problemas del mundo real.

---

## 🚀 Tecnologías Utilizadas

A continuación se describen brevemente las tecnologías principales que conforman el ecosistema de aprendizaje de la materia:

### 🟢 Node.js
Entorno de ejecución para JavaScript basado en el motor V8 de Chrome. Se utiliza para el desarrollo del **Backend y APIs RESTful**, permitiendo conectar las aplicaciones móviles con bases de datos y servicios en la nube.

### ⚛️ React Native
Framework de código abierto creado por Meta. Permite construir aplicaciones móviles nativas para iOS y Android utilizando JavaScript y React, reutilizando gran parte del código entre ambas plataformas sin comprometer el rendimiento nativo.

### 🟣 Kotlin
Lenguaje de programación moderno, conciso y seguro desarrollado por JetBrains. Es el lenguaje oficial recomendado por Google para el **desarrollo nativo en Android**, destacándose por su interoperabilidad completa con Java y su prevención de errores en tiempo de ejecución (como los punteros nulos).

### 🎯 Dart
Lenguaje de programación orientado a objetos desarrollado por Google. Está optimizado para la creación de interfaces de usuario rápidas y reactivas en múltiples plataformas, sirviendo como la base sintáctica de Flutter.

### 💙 Flutter
Framework de UI creado por Google para compilar aplicaciones nativas y de alto rendimiento para móvil (iOS, Android), Web y Escritorio desde una **única base de código** escrita en Dart.
